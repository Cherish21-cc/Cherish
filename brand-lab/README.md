# Brand Lab｜Brand Strategy Workbench

单文件品牌策略工作台（`index.html`），按 Brand Strategy Visualization Skill 第 13 节的启动指令构建。双击即可在浏览器打开，不需要安装任何东西。

- 流程：项目定义 → 市场与竞争 → 消费者洞察 → 品牌定位 → 品牌资产与信任 → 产品与品牌延伸 → 整合传播 → 预算与执行 → 效果评估 → 策略报告
- **规则型原型，未接入 AI**：质量检查与报告汇总都来自页面内写死的规则与模板。
- **无后端**：数据只保存在本浏览器 localStorage（键名 `brandlab.v1`），可在“策略总览 → 项目文件”导出、导入或清空。
- 默认载入虚构品牌「栖山」的**示例数据**，页面会标注；点“新建空白项目”即可从头开始。
- 外部依赖只有 Google Fonts（加载失败时退回系统字体）。

部署：GitHub Pages 选择本分支根目录后，访问 `https://<用户名>.github.io/<仓库名>/brand-lab/`；也可以把 `index.html` 单独拖到 Netlify Drop。

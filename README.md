# 2027 届校园招聘信息汇总

一个中文静态网站，把分散在各处的 **2027 届（27 届）中国校园招聘信息** 整理成一张可筛选、可记录的表。

面向 2027 年 6—7 月毕业、正在跑秋招/春招的同学。

## 收录了什么

**166 家企业与机构**，覆盖 **20 个行业**，每一条都包含：

| 字段 | 说明 |
| --- | --- |
| 公司名称 / 别名 | 含英文名与常见简称，方便搜索 |
| 所属行业 | 互联网、半导体、能源电力、银行、军工、公共部门等 20 类 |
| 公司性质 | 央企 / 国企 / 民营 / 外企 / 事业单位，并标注更细的说明（如「央企 · 国有大行」） |
| 投递渠道 | 官方招聘官网直链 + 公众号 / 内推 / 宣讲会等实际投递方式 |
| 工作地 & 岗位方向 | 总部与主要基地城市、主要招聘的岗位类别 |
| 招聘节奏 | 该公司提前批 / 正式批 / 补录的常见时间窗口 |
| 实用备注 | 例如「国家电网以电气类为主，各省分数线差异极大」「四大审计旺季加班强度大但履历背书强」 |

除企业名录外还有：

- **2027 届校招时间轴** —— 从暑期实习季到最后补招的 7 个阶段，标注每个阶段该做的事
- **我的投递看板** —— 收藏企业、记录「已投递 / 笔试 / 面试 / 已拿 Offer」状态，自动汇总，可导出 CSV
- **通用投递渠道** —— 官网、公众号、宣讲会、牛客、应届生求职网等 10 个信息入口及各自的适用场景
- **求职避坑指南** —— 付费内推、黑中介、三方协议违约金、应届生身份、offer 总包对比等 8 条

## 怎么用

### 在线打开

把仓库的 GitHub Pages 打开即可（仓库 Settings → Pages → Source 选择本分支的根目录）。

### 本地打开

```bash
git clone <本仓库地址>
cd Cherish
# 直接双击 index.html，或者起一个本地服务：
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

### 打包成单个文件发给朋友

```bash
python3 scripts/build-single.py
```

会生成 `dist/index.html`：一个约 130 KB 的自包含 HTML，不依赖任何外部资源，
可以直接通过微信、邮件发送，对方双击就能在浏览器里打开使用。

## 怎么补充和纠错

所有数据都在 **`assets/js/data.js`** 一个文件里，纯文本、无需构建工具。
新增一家公司，就在 `window.COMPANIES` 数组里照着现有格式加一条：

```js
{
  name:"公司名称",
  alias:"英文名 常见简称",              // 用于搜索命中
  industry:"互联网/软件",               // 必须是 INDUSTRIES 里已有的值
  nature:"民营",                        // 央企 / 国企 / 民营 / 外企 / 合资 / 事业单位
  natureSub:"民营 · A股上市",           // 卡片上显示的性质说明
  hq:"深圳",
  cities:"深圳 北京 上海",
  roles:"研发 产品 运营",
  url:"https://example.com/campus",     // 官方投递入口
  channel:"官网网申 + 公众号「XX招聘」",
  timeline:"8—10 月",
  tags:["大厂","提前批"],
  note:"给求职者的实用提醒"
}
```

保存后刷新页面就能看到，行业/性质/标签的筛选按钮和数量会自动更新。

改完可以跑一下数据自检：

```bash
node -e "global.window={};require('./assets/js/data.js');
  const c=window.COMPANIES, i=new Set(window.INDUSTRIES), n=new Set(window.NATURES);
  c.forEach(x=>{ if(!i.has(x.industry)) console.log('行业不在列表:',x.name);
                 if(!n.has(x.nature))   console.log('性质不在列表:',x.name); });
  console.log('共',c.length,'条，校验完成');"
```

## 会员入口怎么启用

网站本身**不收款、不做用户系统**——付费内容放在知识星球 / 小报童 / 小鹅通这类平台，
由平台代收、处理退款和发票，你在平台提现到银行卡。网站只做免费引流。

启用三步：

1. 在平台开好你的星球 / 专栏
2. 打开 `assets/js/data.js`，找到 `window.MEMBERSHIP`，把链接填进 `url`
3. 按实际情况改 `platform`、`name`、`price`、`includes`

```js
window.MEMBERSHIP = {
  enabled: true,
  platform: "知识星球",
  name: "2027 校招更新圈",
  url: "https://t.zsxq.com/你的链接",   // ← 填这里
  price: "￥49 / 年",                   // 留空则不显示
  includes: [ /* 会员包含什么 */ ],
  excludes: [ /* 明确不包含什么 */ ]
};
```

`url` 留空时页面显示「链接待填写」，不会出现一个点了没反应的坏按钮。
把 `enabled` 改成 `false` 可以整块隐藏。

**`excludes` 里的两条请不要删**：

- 不提供内推、不代投简历、不承诺 offer
- 网站上这 166 家企业的信息永久免费，不会被挪进付费区

网站避坑指南的第一条就是「付费内推一律不要碰，正规企业的内推永远免费」。
付费内容一旦涉及内推或代投，整个站的立场就站不住了，而且可能触及
职业中介的监管范围（需要人力资源服务许可证）。卖持续的人工跟进可以，卖这张表不行。

另外两件事自己确认：收入要报税；如果以后想让网站自己收款而不是走平台，
需要营业执照 + 商户号 + 对公账户 + ICP 备案，个人收款码不能用于经营性收款。

## 每次更新数据后

在 `assets/js/data.js` 的 `window.CHANGELOG` 最前面加一条，页面的「持续更新」
板块会自动显示，顺便把 `SITE_META.updated` 改成当天日期：

```js
window.CHANGELOG = [
  { date: "2026-10-08", items: ["国家电网二批网申开放", "新增 3 家半导体企业"] },
  // ...旧的记录往下排
];
```

这块是会员制能成立的依据——让人看见你确实在持续投入。

## 项目结构

```
index.html                 页面结构
assets/css/style.css       样式（含深色模式）
assets/js/data.js          全部数据、会员配置、更新日志 —— 要改内容只需要动这个文件
assets/js/app.js           筛选、搜索、收藏、投递状态、CSV 导出
scripts/build-single.py    打包成单文件 dist/index.html
```

技术上是纯静态页面：没有框架、没有构建步骤、没有外部依赖、不发任何网络请求。
收藏与投递状态保存在浏览器的 localStorage 里，**不会上传到任何服务器**。

## 重要说明

本项目是**个人整理的公益信息汇总**，数据基于公开信息编排，**不代表任何企业的官方立场**。

校招的批次时间、岗位要求、招聘规模每年都会变动，官网链接也可能调整。
**请务必以各公司官方招聘网站与官方公众号发布的公告为最终依据。**
如果卡片上的「投递入口」打不开，用旁边的「搜一下」按公司名搜索最新公告。

本站不收取任何费用、不提供内推、不代投简历。任何声称与本项目相关并收费的行为都与本项目无关。
